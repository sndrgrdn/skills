# Cover Letter and Application

Use for cover letters, application questions, and personal statements.

- Use sentence case, full punctuation, and consistent British spelling.
- Write three to five paragraphs unless the form imposes another bound.
- Use mostly full sentences, with fragments only for deliberate emphasis.
- Use no emoji or exclamation marks.
- Turn personal-site irreverence into directness rather than swearing.
- Answer why the role is worth choosing, not why the company deserves praise.
- Prefer concrete stack, scope, location, and autonomy fit over mission statements.
- `For me` and `I find` can own a judgement. Remove them only when they dilute a factual claim.
- If the draft sounds curated, return to spoken thought shape and clean only the grammar.
