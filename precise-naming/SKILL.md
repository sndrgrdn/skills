---
name: precise-naming
description: Use precise, professional vocabulary when naming or renaming code symbols, files, directories, commands, events, statuses, interface text, commits, or branches.
---

Use **specification-grade vocabulary** for every name: precise, professional words an engineer would put in a formal specification. The “1972 IBM engineer” test defines the register, not a historical vocabulary limit; established technical terms remain valid.

Name the actual domain concept, operation, or state. Prefer literal denotation to slang, casual shorthand, chat phrasing, and cute or clever metaphor. Use the shortest exact name.

`deploy_dashboards.sh`, not `push_dashboards.sh`; `Transfer Funds`, not `Move Money`; `Registration Complete`, not `You're in!`; `System Failure`, not `Something is broken`.
