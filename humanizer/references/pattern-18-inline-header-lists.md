# Pattern 18: Inline-header vertical lists

Open this when the text may contain **inline-header vertical lists**.

## Signals

- **Security:** text; 1. Performance: text; bullet label colon description

## Why it reads AI-generated

The format is a common chatbot default. It often turns simple prose into a rigid labeled list.

## False positives

- Human writers may use this pattern deliberately for genre, emphasis, or local style.
- Treat one instance as weak evidence. Treat repeated use with other tells as stronger.
- Preserve the pattern if it is required by a style guide, quote, code, citation, or the user's sample voice.

## Rewrite strategy

Convert to prose or plain bullets. Keep labels only for genuinely scannable reference material.

## Before

> - **Security:** Login now supports passkeys.
- **Performance:** Pages load faster.

## After

> Login now supports passkeys, and pages load faster.

## Audit question

Does the rewritten sentence say something specific that the original actually supports, or did it merely hide the tell?
